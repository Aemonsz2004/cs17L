# Pandarawan RTMS — Agent Guide

## Stack

- **Backend**: Laravel 13, PHP 8.3+, Pest 4 (Feature + Unit), Pint (`laravel` preset)
- **Frontend**: React 19, Inertia 2, Vite 8, Tailwind CSS 4, JSX (no TypeScript), Prettier (4-space indent, single quotes, tailwindcss plugin)
- **E2E**: Playwright (`tests/e2e/`)
- **Queue / Cache / Session**: database-driven (`.env` defaults)

## Commands

| Task | Command |
|------|---------|
| Dev server (PHP + queue + Vite) | `composer run dev` |
| Dev server with SSR | `composer run dev:ssr` |
| Full setup (fresh clone) | `composer run setup` |
| PHP lint (Pint) | `composer run lint` / `composer run lint:check` |

| CI gate | `composer run ci:check` |

**Note**: `npm run types:check` (called in `ci:check`) does **not exist** — it's stale.

## Architecture

- **Router**: Single `routes/web.php` with three role-guarded groups (`admin`, `tenant`, `applicant`) via middleware aliases registered in `bootstrap/app.php:34-38`.
- **Model binding**: `{notification}` resolves to `RtmsNotification` (not the default model) — defined in `bootstrap/app.php:16-19`.
- **PayMongo webhooks**: Route `/webhooks/paymongo` exempt from CSRF (`bootstrap/app.php:29-31`).
- **Wayfinder**: Codegen tool that generates typed route helpers in `resources/js/routes/` and `resources/js/wayfinder/`. Regenerate after route changes.
- **SSR**: Enabled (`config/inertia.php`). Inertia SSR server runs on port 13714. Use `composer run dev:ssr` to develop with SSR.
- **React Compiler**: Enabled via Babel plugin in `vite.config.js:16-18`.

## Conventions

- **Frontend aliases**: `@/` → `resources/js/` (jsconfig.json)
- **Tailwind CSS v4**: No `tailwind.config.js`. Configured via `@import "tailwindcss"` in CSS.
- **ESLint**: Import ordering enforced (builtin → external → internal → parent → sibling → index, asc). Braces required on all control statements (`curly: all`, `1tbs` style). Blank lines required around control flow keywords.
- **Generated/third-party files ignored by lint**: `resources/js/actions/**`, `resources/js/components/ui/*`, `resources/js/routes/**`, `resources/js/wayfinder/**`
- **Prettier ignores**: `resources/js/components/ui/*`, `resources/views/mail/*`
- **Testing**: Feature tests use `RefreshDatabase` with SQLite `:memory:`. Pest factories not used in tests — helpers like `makeTenant()` are defined inline in test files.
- **E2E**: Playwright config at root. Tests target `http://127.0.0.1:8000`. Web server started automatically by Playwright via `php artisan serve`.

## Setup Quirks

- `.npmrc` hoists `@inertiajs/core` to avoid resolution issues.
- OTP requires working SMTP. For testing, `phpunit.xml` sets `MAIL_MAILER=array`.
- Queue worker required locally for email delivery (`php artisan queue:listen --tries=1`, included in `composer run dev`).
- After changing `.env`, run `php artisan config:clear`.
- After adding routes, regenerate Wayfinder files.

## Ownership Boundaries

| Directory | Purpose |
|-----------|---------|
| `app/Http/Controllers/` | Split into `Auth/`, `Admin/`, `Tenant/`, `Applicant/`, `Site/`, `Webhook/` |
| `app/Models/` | 12 models including `User`, `Tenant`, `Unit`, `Invoice`, `RentalApplication` |
| `resources/js/pages/` | Inertia page components, mirrors controller namespaces (`admin/`, `tenant/`, `applicant/`, `public/`) |
| `resources/js/components/` | Shared UI components (Button, Card, Modal, Table, etc.) |
| `resources/js/routes/` | Auto-generated by Wayfinder — do not edit manually |
